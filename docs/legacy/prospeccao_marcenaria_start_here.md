# Start Here - Prospecção Marcenaria

Leia primeiro o arquivo [prospeccao_marcenaria_antigravity.md](./prospeccao_marcenaria_antigravity.md) e siga exatamente a ordem de execução descrita nele.

## Instrução curta para o agente

Você vai implementar um módulo nativo de prospecção comercial dentro do ERP D'LUXURY CRM.

Faça exatamente nesta ordem:

1. Ler o arquivo principal de instruções.
2. Inspecionar a base atual do projeto.
3. Reaproveitar o que já existir antes de criar algo novo.
4. Implementar schema, backend, frontend e integrações.
5. Validar cada fase antes de avançar.
6. Entregar relatório final com o que foi criado, reaproveitado e pendências.

## Regras de operação

- Não criar app separada.
- Não quebrar tenant isolation.
- Não duplicar lógica já existente.
- Não assumir dados ausentes.
- Não inventar campos nem fontes.
- Registrar auditoria nas operações críticas.
- Entregar tudo integrado ao ERP.

## Definição de pronto

O trabalho só termina quando:

- o módulo estiver implementado no ERP
- os leads puderem ser capturados, enriquecidos, deduplicados e pontuados
- as telas principais funcionarem
- o funil e o relatório estiverem prontos
- a integração com o CRM estiver funcionando

## Saída esperada do agente

Ao final, o agente deve devolver:

- resumo executivo
- arquivos criados
- arquivos alterados
- tabelas criadas
- validações executadas
- problemas encontrados
- próximos passos
